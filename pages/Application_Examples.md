## D1 跟随控制

基于 Intel D435i 深度相机与 UWB 的跟随控制示例。

[查看 GitHub 仓库](https://github.com/DDTRobot/d1-follow-control)

```{warning}
此示例会占用 `SDK mode`，安装后开启该模式即进入跟随控制；不再使用时建议卸载。

请在空旷区域测试，避开玻璃与强反光物体。相机视野有限，机器人周围仍存在盲区及碰撞风险。操作前请完整阅读仓库中的注意事项。
```
