# Application examples

This page collects D1 application examples with brief descriptions and source links. Refer to each repository's README for installation steps, usage, and parameters.

(d1-follow-control)=
## D1 follow control

A following-control example based on the Intel D435i depth camera and UWB.

[View GitHub repository](https://github.com/DDTRobot/d1-follow-control)

```{warning}
This example uses `SDK mode`. Once installed, enabling that mode starts follow control. Uninstall the package when it is no longer needed.

Test in an open area, away from glass and highly reflective objects. The camera has a limited field of view, leaving blind spots around the robot and a risk of collisions. Read all precautions in the repository before operating the robot.
```
